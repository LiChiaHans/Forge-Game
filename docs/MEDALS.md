# 紀念章規則（2026/11/19）

圖鑑館 → 紀念章，分為四季、遠征、工藝與生活三組，共14枚、最高34星。
首頁保存跨局最高星級；遊戲中的計數與進度都屬於本局，新遊戲重新開始。沒有額外能力加成。

## 四季紀念章

| 名稱 | 一星（原目標） | 二星 | 三星 |
| --- | --- | --- | --- |
| 春芽花冠章 | 播種1盆屬性花、售出含配菜料理3道 | 播種2盆、售出6道 | 播種3盆、售出9道 |
| 海風珍貝章 | 售出鐵級以上武器3把、香氣≥20料理3道 | 各6件 | 各9件 |
| 豐收楓葉章 | 燒掉3格落葉、售出含兩份以上配菜料理3道 | 各6格／道 | 各9格／道 |
| 暖爐雪晶章 | 售出鋼級以上武器3把、飽足≥26料理3道 | 各6件 | 各9件 |

- 每次出現該季，都有三天完成兩項任務；第三天起可領獎。
- 領取一星後，下次該季挑戰二星；完成二星後，下次該季挑戰三星。未完成維持原難度，三星後持續三倍目標。
- 提高的是數量，不改最低階級／能力門檻。金幣與裝飾獎勵維持原本400／600／800／1000及各季原裝飾。
- 一季只領一次，不能同季連領一至三星；已完成未領取的獎勵保留最近8季。
- 舊版已取得紀念章轉成一星；進行中的舊任務維持一星原目標。

製作成就只計指定階級的一般武器／料理，合成完成即計入，不必販售。同階不同品項可一起累計，金級與秘銀、四階與五階分開計數。數字是本局總數，不是各星級額外再做的數量。

裝飾依擁有總件數計算，包含收藏與已放置、不同季節和日夜款，同款多件各算一件。收花依成功收成的盆栽數，每盆一朵；春天雙份精華仍只算一朵，抽到精華不計。

舊存檔可由製作經驗、遠征通關與裝飾庫存補算成就。舊版沒有收花總數紀錄，收花成就從這次更新後開始累計。後台與測試不影響正式收藏。
